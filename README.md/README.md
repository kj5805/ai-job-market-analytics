# AI Job Market Analytics

An end-to-end data analytics project that explores trends in the AI job market using Python, Pandas, NumPy, Matplotlib, and Power BI.

The project analyzes **6,000+ AI job records** to understand salary patterns, job demand, experience levels, industries, locations, skills, and remote-work trends.

---

## 📌 Project Overview

The AI industry is rapidly evolving, creating demand for professionals across roles such as Data Scientist, Machine Learning Engineer, AI Engineer, Data Analyst, and other technology positions.

This project uses exploratory data analysis and interactive visualization to identify patterns in the AI job market and answer questions such as:

- Which AI roles are most in demand?
- How does salary vary with experience?
- Which industries offer higher salaries?
- Which locations have greater job demand?
- Which skills are associated with higher salaries?
- How does remote work availability vary?
- What skills provide strong opportunities in the AI job market?

---

## 🎯 Objectives

- Clean and prepare real-world job market data
- Perform exploratory data analysis (EDA)
- Analyze salary distributions and trends
- Compare job demand across roles, industries, and locations
- Study the relationship between experience and salary
- Analyze skills and their salary impact
- Examine remote job opportunities
- Build an interactive Power BI dashboard
- Communicate analytical findings through clear visualizations
